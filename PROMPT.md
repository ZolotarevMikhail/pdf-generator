# Промпт, по которому создавался проект

## Исходный (из урока)

Напиши Python-скрипт, который читает все CSV и JSON файлы в директории /data,
читает HTML-шаблоны из /templates, выводит меню для выбора файла данных,
шаблона и конкретного invoice_id, по выбранному документу подставляет данные
в шаблон и генерирует PDF в /output через WeasyPrint, затем открывает его
системной программой. Поддержка кириллицы, работа на Windows и macOS,
аккуратное меню с нумерацией.

## Что я добавил в промпт при работе с Claude Code

- только стандартные библиотеки Python + WeasyPrint (без pandas);
- сумма по позициям считается скриптом, в шаблоне метка {{ total }};
- понятные сообщения об ошибках на русском: пустой файл, нет колонки
  invoice_id, не установлена библиотека, не хватает системных библиотек;
- суммы с разделением тысяч (25 000, а не 25000);
- имена файлов PDF берутся из invoice_id (INV-001.pdf);
- данные перед подстановкой экранируются, чтобы текст из таблицы
  не мог сломать разметку шаблона.

## Ход работы

Промпт → скрипт (я вставлял и запускал сам) → установка WeasyPrint →
ошибка с системной библиотекой libgobject → `brew install pango` →
потребовалась подсказка запуска DYLD_FALLBACK_LIBRARY_PATH →
живой прогон на трёх демо-счётах → проверка PDF глазами.
